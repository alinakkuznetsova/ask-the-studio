# Returns Policy

This policy applies to orders delivered between 1 January 2025 and 31 December 2025.

## Returns window
You can return unworn items in their original packaging within 14 days of delivery.

## Refunds
Returns are refunded as store credit only. Store credit is valid for 12 months.

## Earrings
Earrings can be returned only if the hygiene seal is unbroken.

## Gifts
Gift returns are not accepted.

## How to start a return
Email hello@parurelondon.com with your order number.
